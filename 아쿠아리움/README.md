# 🌊 아쿠아리움: 지하수 함양 특성 분석 및 AI 기반 지하수위 예측 프로젝트

**아쿠아리움 팀**은 2025 DATA·AI 분석 경진대회 문제해결 분야에 참가하여  
**기후·강수 요인을 반영한 지하수위 변동 예측 모델**을 구축하고,  
지점별 함양 특성을 정량적으로 분석하는 데이터 기반 연구를 수행하였습니다.

---

## 🎯 프로젝트 개요

- **참여 대회:** 2025 DATA·AI 분석 경진대회 (문제해결 분야)  
- **주제:** 지속가능한 수자원을 위한 지하수 함양 특성 분석 및 AI 기반 지하수위 변동 예측  
- **활동 기간:** 2025.08.19 ~ 2025.10.16  
- **리더보드 결과:** 14팀 중 13위  

지하수는 기후변화 시대의 핵심 수자원입니다.  
본 프로젝트는 **시간 단위 지하수·기상 데이터를 활용하여 지하수위(elev)를 예측**하고,  
강수–지하수 간 반응 시차(lag) 및 지점별 수문 특성을 분석하는 것을 목표로 합니다.

---

## 📊 데이터 설명

본 프로젝트는 대회 주최 측(AIDA 플랫폼)에서 제공한 데이터를 활용하였습니다.

### 🔹 지점 정보 (12개 관측소)

- 위도
- 경도
- 수리전도도
- 표고(EL_m)
- 권역 정보(river)

### 🔹 시계열 데이터

| 구분 | 기간 | 포함 변수 |
|------|------|------------|
| Train | 2014–2020 | 지하수위, 기온, 강수량, 전기전도도, 수온, 기압 등 |
| Test | 2021–2023 | 기상 변수 (지하수위 제외) |

- 관측 단위: **시간(hourly)**
- 타깃 변수: `elev` → 모델링 시 `y`로 변환

---

## 🧠 문제 정의

> 과거 7년(2014–2020)의 시계열 데이터를 기반으로  
> 미래 2021–2023년 지하수위를 예측하는 다지점 시계열 예측 문제

- 다변량(multivariate) 문제
- 강수 반응 시차 존재
- 계절성 + 비정상적 급변 구간 존재
- 일부 지점 데이터 품질 불균형

---

## ⚙️ Feature Engineering

### 1️⃣ 결측치 처리
- 시간 연속성 보장을 위한 선형 보간
- 강수 보간 여부 구분 플래그 추가  
  → `is_precipitation_missing`

### 2️⃣ Lag 변수
- `elev_lag_168h` (7일)
- `elev_lag_336h` (14일)
- `elev_lag_504h` (21일)
- 초기 구간 대체 여부 플래그 포함

### 3️⃣ 누적 강수량
- `sum_of_rain_24h`
- CCF 분석 결과(10–36시간 반응)를 반영한 설계

### 4️⃣ 정적 변수
- 위도, 경도
- 수리전도도
- 표고
- river (categorical)

### 5️⃣ 시간 파생 변수
- hour
- dow
- month
- time_idx

---

## 🤖 모델링 전략

### 🔹 모델 선택 과정
- Random Forest → 변수 중요도 분석
- LSTM → 급변 구간 대응 한계
- **최종 모델: Temporal Fusion Transformer (TFT)**

TFT는 다음과 같은 특징을 가집니다:

- 다변량 입력 처리 가능
- 다지점 동시 학습 가능
- 장기 의존성 반영
- Attention 기반 구조

---

## 🏗️ 학습 설정

- Train: 2014–2018  
- Validation: 2019–2020  
- Encoder Length: 168h  
- Prediction Length: 24h  
- Loss: Quantile Loss (0.1, 0.5, 0.9)  
- Optimizer: Adam  
- Epoch: 3  
- Framework: PyTorch Lightning  
- Hyperparameter Tuning: Optuna  
- Mixed Precision: bf16  

---

## 📈 성능 평가

### 🔹 평가 지표
- **NSE (Nash–Sutcliffe Efficiency)**
- **KGE (Kling–Gupta Efficiency)**

### 🔹 검증 구간 평균 성능
- 평균 NSE ≈ 0.27
- 평균 KGE ≈ 0.81

- 일부 지점(6번)에서는 높은 재현성 확인
- 일부 지점(10번)에서는 NSE 음수 → 지역 일반화 한계 존재

## 🚧 한계 및 개선 방향

1. **Data Drift 문제**
   - 2021년 이후 강수 패턴 변화

2. **관측 불균형**
   - 일부 지점 결측 과다

3. **지역 특성 반영 부족**
   - 저투수 지역에서 성능 저하

4. **학습 자원 제약**
   - GPU 한계로 epoch 부족

### 🔮 향후 개선 방향
- 장기 학습 수행
- 지점별 fine-tuning
- 추가 수문 변수 확장
- 장기 기후 인덱스(ENSO 등) 반영
