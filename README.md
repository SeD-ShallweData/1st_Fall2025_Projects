# 🍁 Shall we DATA·AI? 🍁  
> **SeD 1st 하반기 활동 산출**  
> *from Structure to Submission*

---

## 🧭 Overview

2025년 하반기, SeD 1기는  
상반기 내부 데이터톤 경험을 기반으로  
**실제 AI·데이터 분석 경진대회 참가형 프로젝트**를 수행했습니다.

이번 학기의 핵심은 단순한 분석 결과가 아닌,

> **팀 분업화 → 과정 중심 학습 → 실전 대회 제출 → 포트폴리오 확장**

이라는 구조적 Workflow를 구축하는 것이었습니다.

---

## 🏗 운영 방식

상반기 활동에서 발생했던 참여 편차와 역할 불균형을 보완하기 위해,  
하반기에는 **회사식 운영 + 책임제 + 분업화 시스템**을 도입했습니다.

- 2개 팀 체제 운영 (각 5명 내외)
- 팀별 **리더(사수)** 지정
- 역할 기반 분업 구조
  - Data Engineering
  - EDA & Feature Engineering
  - Modeling & Validation
  - Documentation & Presentation
- 주 1회 팀 회의 (의무)
- 정기 세션: **결과 중심이 아닌 과정 중심 브리핑**

정기 세션에서는 단순 결과 발표가 아니라  
데이터 수집·전처리·모델링 과정과 문제 해결 경험을 공유하는 방식으로 운영되었습니다.

## 🏛 TEAM 1 — CLUSTER

### 📌 뉴스·소셜 토픽 추출 및 입법예고 연계를 통한 입법수요지수(LDI) 산출 모델

CLUSTER 팀은 방대한 규모의 **비정형 뉴스·소셜 데이터**를 분석하여  
실시간 사회적 담론을 추출하고, 이를 실제 **국회 입법예고 데이터**와 연계하여  
정량화된 **입법수요지수(LDI)**를 산출하는 의사결정 지원 플랫폼을 설계하였습니다.

### 🔍 Key Contributions

- 뉴스·소셜 데이터 수집 및 전처리
- NLP 기반 토픽 추출
- 입법예고 데이터 매핑 로직 설계
- LDI 산출 지표 정의
- 정책 의사결정 지원 지표 제안

> 사회적 이슈와 정책 반응 간의 정량적 연결을 시도한 프로젝트

## 🌊 TEAM 2 — AQUARIUM

### 📌 지하수 함양 특성 분석 및 AI 기반 지하수위 예측

AQUARIUM 팀은 2025 DATA·AI 분석 경진대회 문제해결 분야에 참가하여,  
기후·강수 요인을 반영한 **지하수위 변동 예측 모델**을 구축하였습니다.

### 🔍 Key Contributions

- 지점별 지하수 데이터 정제
- 강수·기후 변수 반영
- 시계열 기반 예측 모델 설계
- 지점별 함양 특성 정량 분석

> 환경 데이터 기반의 실질적 예측 모델 구현
